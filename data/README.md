# data/ — конвенции

## Slug-контракт зеркала (НЕ «чинить»!)

Ключ зеркального файла = слаг upstream-относительного пути:
не-`[A-Za-z0-9.]` → одиночный `_`, крайние `_` отброшены
(`current/sprint.json?limit=100&offset=0` → `current_sprint.json_limit_100_offset_0`).
Поэтому в именах встречается `.json` посреди имени и «нет расширения» — это
НОРМА: слаг обязан побайтово совпадать с приложением
(`SnapshotMirror.slug`, Swift). Парные тесты: `src/mirror.test.ts` ↔
`OverlapTests/SnapshotMirrorTests.swift` — менять только вместе.

## Зона: кухня / витрина / справочник

Перед публикацией приложения сырьё уезжает в приватный репозиторий, наружу
остаётся витрина — это единственный реальный механизм закрытия правового риска
редистрибуции. Граница записана как ДАННЫЕ в `src/lib/databoundary.ts` и стоит
под сторожем охвата: новый каталог в `data/` обязан получить зону осознанно.

Замерено 30.08.2026: кухня была 93 МБ из 105. 31.08.2026 снимок статики FOM
(39 МБ) переехал в приватный репозиторий — читателей у него не было вовсе, ни
на клиенте, ни в сборке.

| Зона | Пути | Клиент читает |
|---|---|---|
| кухня | `f1/jolpica` (1.4 МБ) | **ДА — блокер сплита** |
| заготовка | `f1/openf1` (9.7 МБ), `wec/facts` (0.40 МБ), `f1/pitawards` | `f1/openf1` — ДА (каскад архива 2023–24, хвост фазы 6); остальные — нет |
| витрина | календарь, события, заявка, штрафы, победители, хайлайты, вехи, погода, история, зачёты серий | да |
| справочник | `refs/`, `tracks/`, `f1/overrides/` | да |

Сплит держит ровно один путь — `f1/jolpica`: вызовы jolpica у клиента идут
mirror-first, то есть приложение читает сырьё напрямую. Фаза 6 снимает это
постепенно — файл события заменяет посемейственные запросы.

`wec/facts` — первая «заготовка». Раньше здесь лежали 154 сохранённые
страницы fiawec (24 МБ). Их не переносили в приватный репозиторий, потому что
переносить было некуда: это не склад, а ВХОД СБОРКИ пяти продьюсеров. Вместо
переноса продьюсеры перестали хранить страницы — они разбирают их в памяти в
том же проходе и кладут на диск извлечённое: слаги сезона, расписание уик-энда,
id сессий, строки протоколов. 0.40 МБ вместо 24, витрина на выходе побайтово
та же (проверено пересборкой всех трёх сезонов).

`f1/openf1` — заготовка с 09–10.09.2026 (этапы 1–3 плана
`docs/f1-kitchen-plan.md` §1), тем же плейбуком in-place: каталог и имена
файлов (mirrorSlug) прежние, но сырья и вербатима в них нет. Шесть семейств
класса А (meetings, sessions, drivers, session_result, stints, pit) — тот же
JSON-массив строк, но ТОЛЬКО keep-поля реестра `OPENF1_FIELDS`, канонической
сериализацией; `weather` — колоночный факт-конверт (выход normalizeOpenF1);
`race_control` — R1-массив классифицированных строк, `message` — наш синтез из
фактов, вербатим FIA не переживает запись по построению. 30.4 МБ → 9.7 МБ.
Отличие от `wec/facts`: эту заготовку клиент ЧИТАЕТ — каскад архива 2023–24
(`SnapshotMirror.openF1Path`) жив на keep-подмножестве, снимет его фаза 6;
поимённый инвариант — в `src/databoundary.test.ts`. Осиротевшие файлы (митинг
пропал из `meetings_year_*`, сессия — из листинга) убирает GC писателя с
fail-closed капом 2 единицы за прогон; отменённые митинги — НЕ сироты.

Зона отдельная, потому что факты не кухня (чужого выражения в них нет) и не
витрина (приложение их как правило не читает; исключение выше). Границу держат
сторожа в `src/databoundary.test.ts` («в `data/` нет разметки», охват зон) и в
самих слоях: `MAX_FACT_STRING` у WEC (предел 120; в боевом корпусе медиана 8,
максимум 58), у openf1 — белые списки ключей, `OPENF1_MAX_STRING` (64),
потолки байтов по семействам и walk-тест формы в `src/openf1facts.test.ts`.

**Приватный репозиторий:** `gradora/overlap-data-private`. Продьюсер `fomstatic`
пишет туда: каталог берётся из `FOM_DATA_DIR`, по умолчанию — соседний клон
`../overlap-data-private/data`. Запись в публичный `data/` продьюсер отбивает
явной проверкой — иначе один прогон вернул бы 39 МБ чужой статики обратно.

## Архивные входы (НЕ удалять!)

Срезы `f1/openf1/` за 2023–2024 (meetings/sessions/drivers/stints/… по
meeting_key/session_key тех сезонов) — архивный вход будущих фич
(ретро-лапчарты, пересчёты SC; с 09.2026 — keep-подмножество, полное сырьё
живёт в приватном raw-зеркале). Решение владельца — держать в репозитории
(DATA-PLAN, фаза 0.5). GC зеркала (этап 4) им НЕ угрожает: сиротство меряется
по `meetings_year_*` и листингам, а митинги архивных срезов там живы —
сироты только у выбывших из этих карт файлов.
