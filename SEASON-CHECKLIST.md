# Чеклист смены сезона (N → N+1)

Код бэкенда и приложения переезжает на новый сезон сам: `YEAR` всех продьюсеров
флипается 1 января по UTC, season-guard'ы (`src/season.ts`) закрывают окна
рассинхрона с Jolpica/FIA, WEC/f1-зеркала подхватывают новые сезонные страницы
по мере публикации. Ниже — то, что автоматизации не поддаётся: курируемые
данные. Даты — по традиционному календарю публикаций.

## Исторические сезоны (бэкфилл под переключатель сезонов в приложении)

Данные текущего сезона копятся сами: продьюсеры пишут year-именованные копии
(`data/f1/jolpica/<год>.json`, `<год>_<раунд>.json`), поэтому закрывшийся сезон
уже лежит в зеркале и **отдельного бэкфилла не требует**. Бэкфилл нужен только
для сезонов, которых приложение не застало (2025 добит 02.08.2026).

Как добить сезон N задним числом (порядок важен — derived читают зеркало):

```bash
SEASON=N npm run f1          # historic-режим: <N>.json, <N>/results.json (пагинация),
                             # <N>/sprint.json, зачёты, пер-раундовые слайсы
SEASON=N npm run openf1      # historic backfill: сессии, протоколы, стинты, питы, рейс-контрол
SEASON=N npm run wec         # /en/season/<N> + страницы этапов
SEASON=N npm run imsa        # ТРЕБУЕТ SCHEDULE[N] в src/lib/schedule.ts
SEASON=N npm run f1winners && SEASON=N npm run f1milestones && SEASON=N npm run f1highlights
SEASON=N FIA_BACKFILL=24 npm run fia   # штрафы стюардов по всем раундам
```

Грабли, уже пойманные:
- `f1` без historic-режима молча зеркалил ТЕКУЩИЙ сезон под именем N —
  прогон рапортовал успех, а данных не появлялось (починено: `historicSeason()`).
- derived-продьюсеры читали расписание жёстко из `current.json` — теперь через
  `scheduleMirrorFile(YEAR)` (`src/lib/mirror.ts`).
- У IMSA одна трасса за сезон может принимать И наш этап, И уикенд другой серии
  (2025: `03_Watkins Glen` + `14_Watkins Glen`) — продьюсер перебирает всех
  кандидатов, а не берёт первого по листингу.
- `FIA_BACKFILL` по умолчанию 2 — для полного сезона нужно 24, иначе добьются
  только первые раунды.

## Август–сентябрь (публикация календарей)

- [ ] **`SCHEDULE[N+1]` в `src/schedule.ts`** — календарь IMSA публикуют в
  августе (после Road America). Это единственный жёсткий блокер: без него
  продьюсер imsa падает с 1 января ежечасно (fail-loud задуман, но письма
  каждый час). Round/name/venue/даты; venue должен матчиться с будущими
  папками Al Kamel (`matchTrack`), а для карточных продьюсеров
  (imsafia/imsahighlights/imsawinners) — с `matchImsaTrack`
  (`src/alkamelimsa.ts`): новая трасса или переименование = новый алиас.
- [ ] Проверить, что fiawec опубликовал `/en/season/N+1` (обычно к осени уже
  есть; в 2026 страница 2027 была live уже в июле) — тогда WEC-межсезонье
  пройдёт гладко само.

## Осень (составы и медиа — репо overlap-assets и приложение)

- [ ] Медиа событий: конвенция ТРАССА-ключей (не номеров раундов, миграция
  07.2026): общий файл трассы `images/{f1,wec,imsa}/events/<trackKey>.MP4` +
  постер `<trackKey>-.jpg`; годовое переопределение — те же имена в подпапке
  `<YY>/`. Ключ = MediaKey.slug приложения. Без файла трассы карточка — серая
  заглушка. Заливать можно по мере анонсов.
- [ ] Приложение, карты составов (протухают тихо):
  - `WECManufacturer.carNumbers` — **самая опасная**: устаревший номер отдаёт
    УВЕРЕННО неверную марку (не пропуск!). Сверить весь грид.
  - `WECStanding.driverFlags` — новые пилоты без записи = пустой вырез флага.
  - `TeamColors` / `F1TeamSlug` — новые команды/ребрендинги F1.
  - `F1CircuitFacts` — спринт-сетка нового сезона (lapsSprint!), компаунды,
    счётчики «по N-1», contractUntil; `SeriesEventFacts` — счётчики изданий.
  - Новые трассы: координаты (`WeatherService`), контур (assets + slugOverride),
    таймзона IMSA (`trackTimeZone`), `TrackFacts`.
  - Портреты новых пилотов и лого команд в overlap-assets.
